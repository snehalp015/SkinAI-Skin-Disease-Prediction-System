# SkinAI - Skin Disease Prediction System

## Overview
SkinAI is an AI-powered web application that predicts skin diseases from uploaded images using Deep Learning and Computer Vision.

## Features
- Skin disease prediction
- Confidence score
- Disease information
- Risk assessment
- User-friendly web interface

## Technologies Used
- ReactJS
- Flask
- TensorFlow
- MobileNetV2
- OpenCV
- SQLite

## Dataset
HAM10000 Dataset

## Workflow
Image Upload → Image Processing → MobileNetV2 Model → Disease Prediction → Results Display

## Diseases Detected
- Melanoma
- Basal Cell Carcinoma
- Actinic Keratosis
- Benign Keratosis
- Melanocytic Nevus
- Dermatofibroma
- Vascular Lesion
